## Development

This project uses Astro with the Cloudflare adapter. Start the local dev server with:

```
pnpm run dev
```

(This runs `astro dev --port 4321` under the hood. Use `pnpm run dev:worker` after a build to test the built Cloudflare Worker.)

Run tests with:

```
pnpm test:run
```

Build the project with:

```
pnpm build
```
